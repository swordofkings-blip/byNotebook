# 📖 byNotebook - NotebookLM 対話型ロールプレイ環境

> **Google NotebookLM × AIエージェントで創る、設定破綻や不自然さをできる限り抑えた対話型ライトノベル体験を目指すプロジェクト**

AIロールプレイや対話型小説でよく課題になる**「途中で設定を忘れる」「キャラ崩壊」「不自然な知ったかぶり（全知化）」「オウム返しの多用」**を、Google NotebookLMの強力なRAG技術と専用プロンプトアーキテクチャによって少しでも減らし、より自然で没入感のある物語体験を目指して構築している対話型ノベル環境です。

---

## 🌟 目指している体験・工夫している点

* 🧠 **設定忘れ・キャラ崩壊の低減を目指して**:
  * NotebookLM（Gemini）のRAG機能をベースに、長編ストーリーでも過去の約束や重要設定をできる限り見失わずに引き継げる構成を試みています。
* 🎭 **不自然な全知化（知ったかぶり）の抑制**:
  * **名前アンロックの試み**: 初対面の人物は「銀髪の少女」等の外見仮名で描写し、作中で名乗られて初めて名前を呼ぶ自然な認知プロセスを促します。
  * **情報格差・認知動線の意識**: 相手の居場所や秘密を最初から知っている体で動くのを防ぎ、「尋ねる」「調べる」といった納得感のある動線を経るようプロンプトで制御を試みています。
* 💬 **人間味のある掛け合い（インターリーブ描写）**:
  * 複数行の入力に対して機械的なオウム返しを避け、セリフの合間に仕草やリアクションを挟むことで、テンポ良く生き生きとした会話の実現を目指しています。
* ⚡ **演出用スラッシュコマンド**:
  * ストーリーの没入感を高めるための仕掛けとして、裏エピソードを覗く `/日記`、本音を探る `/心理`、視界外を描く `/幕間`、挿絵プロンプトを生成する `/イラスト` などのコマンドを用意しています。
* 🚀 **手軽に始められるテンプレート構成**:
  * SF、学園ラブコメ、ファンタジーなど、Markdownで設定ファイルを記述するだけで自分好みの世界観を立ち上げられる環境を目指しています。

👉 **[実際の長文プレイログを見る (DEMO_PLAY_LOG.md)](./DEMO_PLAY_LOG.md)**

## 🚀 クイックスタート

### 1. 前提条件のインストール
NotebookLMをCLI/MCPから操作するツールをインストールします。

```bash
npm install -g notebooklm-mcp-cli
```

### 2. Google認証
ターミナルで以下を実行し、Googleアカウントでログインします。

```bash
nlm login
```

### 3. 新しい世界観を作る

#### 方法A：チャットで世界観を伝えてエージェントに作ってもらう（推奨）
AIコーディングアシスタント（Cursor / Windsurf / Antigravity等）にチャットで作りたい物語のテーマを伝えるだけで、ひな形をベースにした設定資料の作成からNotebookLMノートブックの作成・同期まで全自動で行ってくれます。

> 「失恋から始まるビターな青春ものの設定ファイルを作って、NotebookLMにノートを作成・同期して」  
> 「サイバーパンクな世界観で、アンドロイドの相棒と探偵事務所を営む物語ノートを作って」

※1行のシンプルな指定だけでなく、**書き溜めたプロットやキャラクター設定資料をそのままチャットへ貼り付けて**「この設定資料を元にNotebookLM用の各ファイルに整理してノートを作成して」と依頼することも可能です。

#### 方法B：自分で設定ファイルを書いて作成・同期する
1. `worlds/_template/` をコピーして `worlds/<あなたの世界名>/` を作成します。
2. キャラ設定や世界観（Markdown）を自由に編集します。
3. エージェントに同期を依頼します：
   > 「`worlds/<あなたの世界名>/` の設定で新しいNotebookLMノートブックを作って同期して」

### 4. 実際に物語を遊ぶ（プレイ開始方法）
同期が完了したら、PCはもちろんスマートフォンの **Geminiアプリ（連携ノート）** にアクセスして、いつでもどこでも物語を楽しめます。

1. いつも使っている **Gemini（スマホアプリ／Web）の連携ノート**、または [NotebookLM](https://notebooklm.google.com/) から、作成されたノートブックを選択して開きます。
2. チャット欄に、主人公の名前やプロローグ開始の指示を入力して送信します：
   ```text
   ;プロローグ。主人公名は〇〇;
   ```
   ※名前を指定せず `;プロローグ;` のみで開始したり、主人公のセリフ `「よし、行くか」` や行動からいきなり書き始めてもOKです。
3. あとは返ってくる情景描写やキャラクターのセリフを読みながら、自分のセリフ（`「」`）や行動（`**`）、思考（`（）`）を入力して物語を進めるだけです！
