# 初期セットアップ手順書（AIエージェント向け指示書）

ユーザーから以下のように指示された場合、AIエージェントはこの手順書に従って自動で環境をセットアップしてください。

> **トリガーとなる指示の例**:  
> ・「https://github.com/swordofkings-blip/byNotebook をクローンして、この環境が使えるようにセットアップして」  
> ・「この対話型ノベル環境を使えるように導入して」  
> ・「NotebookLMの連携環境をセットアップして」

---

## 🛠 自動実行ステップ

エージェントは以下のステップを順番に確認・実行してください。

### Step 1: リポジトリの配置確認
* **現在の作業ディレクトリに `AGENTS.md` や `worlds/_template` が存在しない場合**:
  ターミナルでリポジトリをクローンしてください。
  ```bash
  git clone https://github.com/swordofkings-blip/byNotebook.git .
  ```
  *(※ディレクトリが空でない場合は `git clone https://github.com/swordofkings-blip/byNotebook.git byNotebook` を実行し、そのフォルダをワークスペースとして開くよう案内してください)*
* すでにリポジトリ内にいる場合はこのステップをスキップします。

---

### Step 2: 依存ツールのインストール（Python / pip）
NotebookLMをCLIおよびMCPから操作するためのツール `notebooklm-mcp-cli` をインストールします。

1. Python環境を確認します：
   ```bash
   python --version
   ```
2. CLIツールをインストールします：
   ```bash
   pip install notebooklm-mcp-cli
   ```
3. インストールが成功したか確認します：
   ```bash
   nlm --version
   ```

---

### Step 3: Google認証の確認と案内
NotebookLMへのアクセス権限を確認します。

1. 認証状態をチェックします：
   ```bash
   nlm login --check
   ```
2. **すでにログイン済みの場合**:
   そのまま Step 4 へ進みます。
3. **未ログインの場合**:
   ターミナルでログインコマンドを実行し、**ユーザーにブラウザでのログインを依頼**してください：
   ```bash
   nlm login
   ```
   *ユーザーへの案内文例*:
   > 「NotebookLMと連携するため、ブラウザでGoogleログイン画面が開きます。ログインが完了したらチャットで教えてください。」

---

### Step 4: 完了報告と「世界観作成」の案内
セットアップが完了したら、ユーザーに準備完了を伝え、次に行うアクション（世界観の作成）を案内してください。

*報告メッセージ例*:
```text
セットアップが完了いたしました！NotebookLM連携ツール（nlm）の準備が整いました。

続いて、あなた好みの物語世界を作成できます。以下のいずれかの方法でお知らせください：

1. 【チャットで丸投げ】
   「失恋から始まるビターな青春ものの物語ノートを作って」
   「サイバーパンクな世界観で、アンドロイドの相棒と探偵をする物語ノートを作って」

2. 【書き溜めた設定資料を貼り付ける】
   ご自身で考えたプロットやキャラクター設定テキストをそのままチャットに貼り付けて「この設定でノートを作って」とご指示ください。

指示をいただければ、設定ファイルの作成からNotebookLMへの同期まで全自動で行います！
```
