# 📖 ワールドシナリオ：『Liar』

> ⚠️ **【二次創作・オマージュに関する明記】**  
> 本作は、ヨルシカ（Yorushika）のアルバム『盗作』およびEP『創作』のコンセプト・世界観・楽曲群に着想を得て制作された、**ファンメイドの非公式二次創作（対話型オマージュシナリオ）**です。  
> 公式および原作者様とは一切関係ありません。個人での対話型ロールプレイ鑑賞・体験を目的としています。

## 🥀 作品あらすじ・概要

深い霧に閉ざされた丘の上に佇む旧式サナトリウム。  
外界の時間をすべて吸い取ってしまったかのような冷たく静まり返った病室で、言葉を失った一人の白皙の青年が、音の出ない鍵盤をなぞるように指を彷徨わせています。

あなたはある明確な事情から、彼が抱える「失われた過去と真実」を聞き出すために、この部屋の扉を開けました。

青年の精神は不可逆的に崩壊しており、日常的な会話は成り立ちません。  
「春」「花」「からくり」「夜の底」「白い目」──彼がぽつりぽつりと零す詩的で痛切な言葉の欠片を丁寧に拾い集め、静かに問いを重ねていくことで、やがて彼の秘められた半生が、鮮烈な追体験として浮かび上がっていきます。

かつて音楽の頂点にいた青年が、なぜすべてを投げ捨てて壊れてしまったのか。  
彼がすべてを失ってまで本当に求めていたものとは何だったのか──。

静寂と哀愁に満ちた、喪失と追憶を辿る対話型ミステリーノベルです。

## 🎮 このワールドの遊び方

本作は**Google NotebookLM（Gemini）**上で動作する対話型ノベルです。  
以下のいずれかの方法でご自身のNotebookLM環境にノートブックを作成し、Geminiとの対話を通じて物語をお楽しみいただけます。

### 方法 1：AIエージェントに自動構築してもらう（最も簡単・推奨）

Antigravity、Cursor、Claude Code、ClineなどのAIエージェントをお使いの場合、チャットで以下のように指示するだけで、ノートブックの作成からソースの登録、プロンプト設定まで全自動で完了します。

```text
worlds/liar/ の設定を使って、NotebookLMにノートブックを新規作成してセットアップしてください。
```

AIが環境を構築し終えたら、発行されたNotebookLMのURLを開き、チャット欄に **「プロローグを描写してください」** と入力して送信してください。

---

### 方法 2：手動でNotebookLMにノートブックを作成して遊ぶ

1. **NotebookLMで新規ノートブックを作成**:
   - [Google NotebookLM](https://notebooklm.google.com/) にアクセスし、「新しいノートブック」を作成します（タイトル例：`物語を紡ぐ：Liar`）。

2. **設定ファイル群をソースに追加**:
   - 本フォルダ（`worlds/liar/`）内の以下のファイルを、NotebookLMの「ソースを追加」からアップロード（またはテキスト貼り付け）します：
     - `world_setting.md`（舞台背景・サナトリウムの設定）
     - `character_sheets.md`（登場人物設定・口調）
     - `memories_and_lore.md`（長期記憶・初期認知マップ）
     - `writing_and_world_lore.md`（演出ガイド・4段階の記憶階層）
     - `prologue.md`（初期導入プロローグ）
     - ※`overview.md`（あらすじガイド。必要に応じて追加）

3. **チャット設定（カスタム指示）の登録**:
   - チャット画面の「チャット設定」（歯車アイコン、またはカスタム指示）を開きます。
   - `worlds/liar/system_prompt.md` の全文をコピーし、「チャットのカスタマイズ」欄に貼り付けて保存します。

4. **物語の開始**:
   - 画面下のチャット欄に、以下のメッセージを入力して送信してください。
     ```text
     プロローグを描写してください
     ```
   - 病室の扉を開けるプロローグが描写され、物語が静かに開幕します。
   - 以降は、男の言葉に耳を傾けながら、自由に問いかけや行動を返信して対話を進めてください。

## 💡 プレイのヒント

- **詩的な比喩に耳を澄ませる**:
  - 男は壊れており、過去の事実を整理して語ることはできません。彼が口にする「花」「春」「からくり」「火種」「夜の底」「白い目」といった言葉の断片に注目して問いかけてみてください。
- **記憶の深層へ**:
  - 男の記憶はトラウマによって固く閉ざされています。初期の段階でいきなり破滅の真相を尋ねても混乱するだけです。まずは彼が囚われている「春」や「花」の記憶から静かに解きほぐしていきましょう。
- **迷ったときは**:
  - 何を聞けばいいか分からなくなった場合でも、AIがプレイヤー（聞き手）の内的思考として「〜について尋ねてみるべきではないだろうか」と自然にヒントを思考整理描写として提示してくれます。焦らず青年の呼吸に耳を傾けてみてください。
